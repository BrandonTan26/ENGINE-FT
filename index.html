Panduan & Tips Ujian FT

Trik memaksimalkan waktu pengerjaan Functional Test tanpa kendala.

1. Standalone di HP Masing-Masing

Semua kisi-kisi yang kamu upload disimpan langsung di memori HP masing-masing melalui IndexedDB Persistent. Tidak ada server terpusat yang bisa down atau lemot saat hari H ujian serentak.

2. Berbagi Kisi-Kisi ke Teman (Kirim via WA)

Jika kamu sudah mengupload file Excel kisi-kisi lengkap di HP kamu, klik tombol "Export JSON" di sidebar/menu. Kirim file `.json` kecil itu ke teman satu toko lewat WhatsApp. Teman kamu tinggal klik "Import JSON" dan bank soal langsung penuh terisi!

3. Sistem Akurasi Warna
> 80% (Hijau): Jawaban sangat presisi dan tepat sasaran.
60% - 80% (Kuning): Soal cukup mirip, cocokkan kembali dengan opsi jawaban kuis.
< 60% (Merah): Kemiripan kata sebagian/parsial.
4. Data Permanen & Tidak Dihapus Browser

Web ini secara otomatis meminta hak akses Persistent Storage ke sistem Android/iOS/Chrome agar browser tidak menghapus database meskipun HP kamu minim memori.
